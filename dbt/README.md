# VitalStream dbt Layer

Analytics-engineering layer over the curated OMOP CDM tables produced by the
Glue ETL pipeline: `sources → staging → marts`, with the pipeline's data
quality checks mirrored as dbt tests.

## Lineage

```
sources (omop):        person · visit_occurrence · measurement
                          │
staging (views):       stg_omop__person · stg_omop__visit_occurrence · stg_omop__measurement
                          │
seed:                  vital_sign_reference  ──►  dim_vital_sign
                          │
marts (tables):        patient_vital_summary
                       abnormal_vitals_by_encounter
                       daily_measurement_counts
```

`vital_sign_reference` is generated from `src/data_generator/vocabulary.py`
by `scripts/generate_dbt_seed.py` — vocabulary.py stays the single source of
truth for LOINC/OMOP mappings, plausible ranges, and alert thresholds. Never
edit the seed CSV by hand.

## DQ checks as dbt tests

| PySpark check (`data_quality.py`) | dbt equivalent |
|---|---|
| Null checks on critical columns | `not_null` tests in `models/staging/_staging.yml` |
| Referential integrity (person / visit FKs) | `relationships` tests in `models/staging/_staging.yml` |
| Clinically plausible ranges | `tests/assert_measurements_within_plausible_range.sql` (driven by `dim_vital_sign`) |

## Targets

- **dev (default)** — [dbt-duckdb](https://github.com/duckdb/dbt-duckdb); the
  `omop` sources read the committed `sample_outputs/` CSVs (themselves
  generated by the real pipeline via `make samples`), so the whole project
  builds and tests locally and in CI with no AWS access.
- **athena** — [dbt-athena-community](https://github.com/dbt-athena/dbt-athena);
  the same sources resolve to the Glue-cataloged `vitalstream_db` tables
  written by the deployed pipeline.

## Running

```bash
pip install dbt-duckdb          # dev target
make dbt-build                  # regenerate seed + dbt build (from repo root)

# or directly:
python scripts/generate_dbt_seed.py
cd dbt && dbt build

# docs:
make dbt-docs                   # dbt docs generate
cd dbt && dbt docs serve        # browse lineage + catalog locally

# against the deployed AWS stack:
pip install dbt-athena-community
export DBT_ATHENA_S3_STAGING_DIR=s3://<athena-results-bucket>/dbt/
cd dbt && dbt build --target athena
```
